# Hudson's Planner

An assignment organizer for one high school student. It runs as a website that installs to the iPhone home screen and the Chromebook.

- **Front end:** static files in `docs/`, hosted on GitHub Pages.
- **Back office:** a Google Apps Script in `apps-script/`, running in the family's Google account. Data lives in a Google Sheet there.

Setup steps are in [SETUP.md](SETUP.md).
